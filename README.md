### 🍒 Cherry Chase

An embedded systems game developed in C for the STM32F031K6 microcontroller.

The player controls an animated character using physical GPIO buttons while the game handles graphics rendering, collision detection and hardware communication.

**Features:**
- Physical GPIO controls
- Animated character sprites
- Collision detection
- SPI display communication
- Custom bitmap graphics
- SysTick-based timing
- Custom graphics and display functions

**Technologies:**  
`C` `STM32` `CMSIS` `PlatformIO` `SPI` `GPIO` `Python`
